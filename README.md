# Лабораторная работа 5
# Дерево поиска и умные указатели

## Цель работы

Реализовать бинарное дерево поиска и контейнер для выборки элементов из дерева. Освоить умные указатели `unique_ptr`, `shared_ptr` и `weak_ptr`, автоматическое управление памятью и полиморфные критерии отбора.

Вариант 5: Point (координаты x и y). Ключом является пара (x, y). Критерий отбора: точки первой четверти (x > 0 и y > 0).

## Классы и управление памятью

| Класс | Назначение | Владение |
| --- | --- | --- |
| `Point` | хранение координат точки | не владеет динамической памятью |
| `Node` | узел дерева | `shared_ptr<Point>` на точку, `unique_ptr<Node>` на детей |
| `Tree` | бинарное дерево поиска | `unique_ptr<Node>` на корень |
| `Criterion` | общий интерфейс критериев отбора | не владеет деревом и точками |
| `Selection` | результат обхода или выборки | `unique_ptr<weak_ptr<Point>[]>` на массив слабых указателей |

Точки сравниваются сначала по x, затем при равенстве x по y. Для сравнения используются операторы `<` и `==`. Повторная вставка точки с теми же координатами запрещена. Для поиска и удаления передаётся точка с нужными координатами, так как оба поля входят в ключ.

Каждым узлом владеет только один `unique_ptr`. При разрушении дерева все узлы удаляются автоматически. Структура `Node` объявлена в `tree.hpp`, корень дерева и вспомогательные методы находятся в закрытой части класса `Tree`.

Сами точки хранятся через `shared_ptr`, так как на них должны ссылаться слабые указатели из выборки. Использовать для этого `unique_ptr` нельзя, так как от него нельзя создать `weak_ptr`. Поиск и выборка не продлевают время жизни точек. После удаления точки слабые указатели на неё становятся истёкшими, если на неё не осталось сильных ссылок. Для доступа к точке используется `lock()`.

Копирование дерева запрещено. При перемещении владение корнем передаётся другому дереву, размер исходного дерева становится равным 0. Для `Selection` реализовано правило пяти: при копировании создаётся отдельный массив слабых указателей, а сами точки не копируются. При перемещении массив передаётся новому объекту, размер и вместимость исходной выборки обнуляются. При заполнении массива его вместимость увеличивается в два раза.

## Краткая справка по использованию

- `insert(point)` - вставка точки, при дубликате возвращается false
- `remove(point)` - удаление точки, при отсутствии возвращается false
- `find(point)` - поиск точки, возвращает `weak_ptr<Point>`
- `size()` - количество точек в дереве
- `height()` - высота дерева (0 для пустого дерева, 1 для листа)
- `inorder()` - симметричный обход по возрастанию ключей
- `reverseInorder()` - симметричный обход по убыванию ключей
- `select(criterion)` - выборка точек по заданному критерию
- `Point::aliveCount()` - количество живых объектов Point

При удалении листа указатель на узел обнуляется. Если у узла один ребёнок, владение ребёнком переносится на место удаляемого узла. Если детей два, выбирается минимальный элемент правого поддерева, его `shared_ptr` переносится в удаляемый узел, после чего узел преемника удаляется. Благодаря этому слабые указатели на точку преемника остаются действительными.

В `Selection` реализованы методы `add()`, `size()`, `capacity()`, `empty()` и доступ по индексу через `operator[]`. После удаления точки из дерева размер ранее созданной выборки не меняется.

## Критерии и обход дерева

`Criterion` является абстрактным классом с виртуальным деструктором и чисто виртуальным методом `matches(const Point&) const`. `FirstQuadrantCriterion` проверяет обе координаты точки в одном методе. В тестах также реализован `TestAllCriterion`, который пропускает все точки. Критерии не хранят дополнительных данных, поэтому для них не требуется собственная реализация копирования и перемещения.

Метод `select()` принимает критерий по константной ссылке. В процессе симметричного обхода каждая точка проверяется на соответствие критерию и при успехе сразу добавляется в выборку. Дерево при этом не меняется. Если ни одна точка не подходит или дерево пустое, возвращается пустая выборка.

Вставка, поиск и удаление имеют сложность O(h), где h - высота дерева. Высота вычисляется за O(n). Обход по критерию выполняется за один проход O(n), память на рекурсию составляет O(h), память под выборку O(k), где k - количество выбранных точек. Дополнительная сортировка не используется. Добавление элемента в выборку имеет амортизированную сложность O(1).

## Ввод и вывод

В `main.cpp` реализовано меню с командами для создания дерева, вставки, поиска, удаления, обходов, выборки по критерию и вывода информации о дереве. Для операций с точкой вводятся две координаты через пробел. При обходе точки выводятся в формате `(x, y)`, истёкшие ссылки выводятся как `[Expired]`.

Написаны 25 тестов Google Test. Проверяются вставка и удаление, дубликаты, поиск, высота, порядок обходов, критерии отбора, копирование и перемещение выборки, перемещение дерева и истечение слабых указателей. После каждого теста счётчик живых объектов Point проверяется на равенство 0.

## Сборка и запуск тестов

Команды выполняются из корня проекта. Если Google Test не установлен, CMake скачивает его из GitHub. Для приложения и тестов используются отдельные цели сборки. При компиляции через GCC используются флаги `-Wall -Wextra -Wpedantic`.

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON
cmake --build build -j 4
ctest --test-dir build --output-on-failure
```

Для запуска приложения в Linux используется `./build/app`, в Windows `./build/app.exe`.

## Проверка памяти

Для Linux или Ubuntu в WSL с поддержкой AddressSanitizer и LeakSanitizer:

```bash
cmake -S . -B build-linux-asan -G Ninja -DCMAKE_BUILD_TYPE=Debug -DENABLE_SANITIZERS=ON -DBUILD_TESTING=ON
cmake --build build-linux-asan -j 4
ASAN_OPTIONS=detect_leaks=1 ctest --test-dir build-linux-asan --output-on-failure
```

Проверка выполнена в WSL, все 25 тестов пройдены, ошибок памяти и утечек в проверенных сценариях не обнаружено.
